# Legacy v1 examples (not maintained)

These examples target the v1 SDK API (`DIDUtils`, `client.payments`, v1 key
helpers), which was removed in 2.0. They are kept for reference only, are not
published to npm, and do not run against the current SDK.

See [`../examples`](../examples) for maintained examples and
[`../docs/MIGRATION.md`](../docs/MIGRATION.md) for API replacements.
